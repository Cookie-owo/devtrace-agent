## Why

当前前端将身份验证、文档、聊天和 AIOps 问题整合到一个临时页面中，因此无法提供可预测的身份验证工作区，也无法在产品范围扩大时安全地进行演变。一个专用的 Vue 应用程序外壳建立了后续产品体验所需的导航、数据访问和反馈边界。

## 什么更改

- 用基于 Vue 3 路由的应用程序外壳替换临时的单页结构。
- 添加公开的身份验证路由以及带有重定向路由守卫的已认证工作区路由。
- 添加响应式导航布局、持久化的已认证 user 菜单，以及用于聊天、知识和 AIOps 体验的中性路由占位符。
- 在前端客户端中集中 typed HTTP 和 SSE 传输，这些客户端使用共享的 API-contract 包。
- 为认证和请求反馈添加应用状态容器，而不将浏览器存储视为领域数据的来源。
- 添加可重用的加载、空状态和 API 错误展示组件。

## 功能

### 新功能
- `vue-app-shell`: 一个类型化、响应式、经过身份验证的 Vue 应用程序外壳，具有共享的前端传输和反馈原语。

### 修改后的功能

无。

## 影响

- 影响`apps/frontend`应用程序组合、依赖项、测试和样式。
- 在UI中不重新定义后端有效负载，复用`packages/api-contracts`中的共享类型和SSE事件定义。
- 建立后续聊天、知识库、AIOps 和引用视图更改所使用的路由和组件接口。
