## Why

AIOps 需要在腾讯云真实环境 CLS 话题中提供安全、可查询的事件证据。一个小型独立脚本就足以生成后续查询所需的代表性日志。

## 什么更改

- 添加一个 Python 脚本，用于生成随机的合成操作日志，包括错误、超时、服务不可用、CPU/内存压力、失败请求、重试和恢复。
- 通过腾讯云的 Python CLS SDK 将生成的批次上传到配置的广州 CLS 主题。
- 为目标区域、端点、日志集、主题和限制批次大小添加跟踪项目配置。

## 功能

### 新功能

- `cls-log-generation`: 从 Python 脚本生成安全的操作测试日志并上传到真实的腾讯云 CLS。

### 修改的功能

- 无。

## 影响

- 影响的区域：后端 SDK 依赖项、项目配置和独立的后端脚本。
- 配置的广州 CLS 主题仅接收合成的操作字段。
