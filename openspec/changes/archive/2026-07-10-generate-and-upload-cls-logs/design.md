## 上下文

该项目需要种子数据以供以后的 CLS 查询使用，而不是应用程序功能。腾讯云的文档化 Python SDK 使用 `LogClient.put_log_raw` 上传 `LogGroupList`。

## Goals / Non-Goals

**目标：** 生成安全的合成操作日志，并将显式请求的有限批次上传到跟踪的广州 CLS 目标。

**非目标:** 无 API、数据库模型、迁移、前端 UI、后台任务、自动启动上传或实际生产日志收集。

## 决策

脚本仅读取跟踪的项目配置，使用官方的 CLS Python SDK，并接受由配置限定的可选 `--count`。它会创建带有随机合成 ID 的固定安全模板；不会在日志中放置任何调用者提供的内容或配置值。

## Risks / Trade-offs

- [无效的凭据或主题] → SDK 命令失败且不打印凭据。
- [合成数据变得嘈杂] → 仅当脚本被调用时才会运行生成。
