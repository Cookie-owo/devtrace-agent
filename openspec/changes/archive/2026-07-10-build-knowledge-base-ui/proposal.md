## Why

该产品已经可以存储 user 范围的知识文档并运行异步 Milvus 索引，但 user 没有用于管理这些资料的交互界面。需要一个专门的工作区，以便操作员可以整理支撑聊天和 AIOps 回答的文档。

## 什么更改

- 用经过身份验证的文档管理工作区替换知识库占位符。
- 通过共享的 API 合同公开当前 user 的知识库、文档元数据、索引状态、失败记录、删除和索引重建。
- 添加受保护的文件上传，包括合同定义的类型和大小策略、重复冲突指导以及显式的覆盖确认。
- 显示异步索引进度而不阻塞工作区的其余部分。
- 保持所有知识数据为服务器端存储且作用于 tenant；浏览器存储不保留任何文档目录或任务状态。

## 功能

### 新功能
- `knowledge-base-ui`: 用于文档上传、索引、检查和删除的经过身份验证的Vue知识库管理。

### 修改的功能
- 无。

## 影响

- 影响`apps/frontend`路由，类型为API边界，Pinia状态，文档管理组件，样式和前端测试。
- 使用来自`@agent-py/api-contracts`的现有文档和索引定义；不需要后端端点或存储合同更改。
