## 上下文

诊断功能已保留报告、证据、工具调用和 user ownership。知识文档已保留类型化元数据，并可以异步索引。已保存的案例必须重用这些边界，而不能将无限制的原始工具负载复制到仅浏览器记录中。

## Goals / Non-Goals

**目标：** 将完成的 owner 范围内的报告保存为内容丰富的知识文档并安排常规索引。

**非目标:** 自动保存每个诊断、更改现有报告或使原始秘密/工具有效载荷可搜索。

## 决策

- 添加一个任务操作端点，该端点需要任务 owner 和已完成的报告。
- 从查询、报告内容和证据摘要中生成一个有限的 Markdown 案例；存储标识诊断 ID 和报告 ID 的源元数据。
- 重用文档仓库创建和现有的索引调度器；通过共享合同返回文档和任务。
- UI 仅对选定的已完成报告暴露该命令并显示返回的状态。

## Risks / Trade-offs

- [重复保存] → 使用确定性报告哈希，并报告业务冲突，而不是静默创建重复案例。
- [证据可能包含敏感内容] → 保留摘要和ID，而不是原始MCP响应负载。
