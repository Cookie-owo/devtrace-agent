## Why

当前的后端仅发出请求完成日志和本地聚合指标。在文档索引、Agent 执行和 MCP 调用之间，无法关联故障和长时间运行的操作，而临时日志可能会泄露凭据或 user 内容。

## 什么更改

- 添加带有 request-id 上下文传播和递归敏感字段遮蔽的共享结构化 JSON 日志边界。
- 生成安全的请求完成和错误日志，保留现有指标。
- 生成安全的生命周期日志，包括文档索引、chat/AIOps Agent 执行以及 MCP 工具调用，包含ID、状态、错误类别和持续时间。
- 添加回归测试，证明事件的相关性覆盖，并且凭据、查询内容、工具参数和工具输出不在日志中。

## 功能

### 新功能

无。

### 修改的功能

- `request-observability`: 从请求完成扩展安全相关日志到请求错误和关键异步执行边界。

## 影响

- 影响FastAPI中间件/处理程序、文档索引、聊天流、AIOps诊断、本地MCP客户端调用、日志测试以及无外部可观测性依赖。
