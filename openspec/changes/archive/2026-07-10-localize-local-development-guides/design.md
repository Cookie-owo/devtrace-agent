## 上下文

经验证的本地优先启动器和文档在技术上已完成，但面向操作员的文本为英文。所请求的项目体验需要中文的文档、启动器消息和解释性文本，同时保留原始命令、文件路径、JSON 字段、URL 和流程行为。

## Goals / Non-Goals

**目标：**
- 将面向 user 的本地开发和操作体验翻译为中文。
- 保留命令执行、配置查找、输出路径、URL 和测试覆盖率。

**非目标：**
- 不要翻译配置键、命令名称、URL 路径或代码标识符。
- 不要修改后端、前端、Docker 或外部集成行为。

## 决策

用户可见的标题、段落、表格、脚本错误和进程状态消息将使用中文。文字性技术标记保持不变，以便操作员可以准确地复制命令并定位跟踪的配置字段。文档测试将断言中文的本地启动标题，并仍然验证不变的命令和路径。

## Risks / Trade-offs

- [翻译会更改一个字面命令] -> 保留 shell 块、路径、端口、JSON 键和工具名称原样，并验证 shell 语法。
- [中文链接使用不稳定的标题锚点] -> 尽可能链接到 README 文件，而不是翻译后的标题锚点。
