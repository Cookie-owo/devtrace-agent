## 上下文

聊天 Agent 将 LangChain `on_tool_start`、`on_tool_end` 和 `on_tool_error` 事件转换为共享的 `tool.call` SSE 事件。该流是实时的：不会写入聊天范围的记录。SQLite 已经有特定于 AIOps 的审计表和仓库方法，但无法将审计附加到聊天会话、更新进行中的通话或向前端提供聊天历史。

实现必须保留仓库边界，tenant 隔离，流式行为和现有的迁移历史。还必须保留遗留的 AIOps 审计表，以确保现有数据库和代码保持兼容。

## Goals / Non-Goals

**目标：**

- 为每个 Agent 工具调用精确保存一条通用审计条目，包含稳定的工具调用 ID、参数、简洁的结果摘要、状态、时间戳、耗时毫秒数和安全的错误消息。
- 将每个条目与一个tenant拥有的父级关联：聊天会话或一个AIOps诊断任务。
- 在保留现有 SSE 事件顺序和终端错误行为的同时，创建或最终确定聊天审计记录。
- 为保留的聊天审计历史提供共享的已认证 API 和前端会话视图。

**非目标：**

- 不要实现 AIOps 诊断执行工作流或其前端。
- 不要持久化无限制的原始工具输出；结果数据会进行汇总以供审计显示。
- 不要修改 Qwen 或知识检索行为。

## 决策

### 引入通用的审计表和仓库

创建 `tool_call_audits` 而不是修改 `aiops_tool_call_audits`。它为 `chat_session_id` 和 `diagnostic_task_id` 提供了可选的外键，一个要求恰好有一个关联的检查约束，owner 作用域的索引，以及一个唯一的工具调用 ID。较旧的表仍保留用于向后兼容；新工作使用由 SQLite 实现的专用 `ToolCallAuditRepository`。

这避免了对 SQLite 表的重建以更改遗留的非空 AIOps 任务外键，保留了迁移的安全性，并使聊天和未来 AIOps 流程具有相同的边界。内存中或 PostgreSQL 实现以后可以满足相同的协议。

### 在流边界处保留生命周期转换

当聊天服务接收到 `started` 时，在生成现有的 SSE 帧之前会写入审计记录。在 `completed` 或 `failed` 时，它会使用确定性的、大小有限的 JSON/text 摘要和完成时间戳来更新该记录；经过的毫秒数是从存储的时间戳中得出的。审计失败会被隔离，因此审计写入不会破坏面向 user 的聊天流，而工具执行结果仍然驱动正常的 SSE 生命周期。

在较低的 LangChain 适配器内部进行录制曾被考虑，但该适配器没有仓库依赖，并会将执行流程与 SQLite 耦合。将持久化保留在 `ChatStreamingService` 中可以保留依赖注入，并让测试运行器使用相同的行为。

### 使用聊天会话审核数据收集端点

添加 `GET /chat/sessions/{sessionId}/tool-call-audits`。它首先通过 owner 作用域的聊天仓库解析会话，然后按时间顺序返回 owner 作用域的记录。响应使用导出的契约类型，字段采用驼峰命名。前端在获取会话详情时会同时获取该数据，并在流处于活动状态时暂时反映 SSE 工具事件。

仔细考虑了每个历史聊天消息中的Embedding审核详情，但这会导致存储重复，并使一次工具调用难以与多个生命周期事件相关联。保留一个单独的集合可以让消息保持稳定的审核ID，同时记录仍可查询。

## Risks / Trade-offs

- [审核写入在流中可能失败] → 捕获并隔离审核持久化失败，保留现有流，并使用仓库测试确保成功的持久化路径。
- [工具输入或输出可能很大] → 在持久化或显示之前，将值归一化为JSON安全值，并截断摘要到有限长度。
- [一个开始事件可能永远不会完成] → 保留`started`状态，并将持续时间设为null，作为中断执行的诚实记录。
- [旧的AIOps表和新的通用表共存] → 将旧表视为不可变的兼容数据；当新AIOps集成实现时，将其路由到通用仓库。

## 迁移计划

1. 添加一个 Alembic 版本，该版本创建 `tool_call_audits`、索引、父级外键和关联检查约束。
2. 添加 ORM、记录、协议和 SQLite 实现，并带有基于 tenant 的父级检查。
3. 连接聊天流、HTTP 合同和前端显示。
4. 运行 Alembic 升级以及所有后端、前端、合同和 OpenSpec 验证套件。

回滚包括在读取新表之前部署之前的应用程序；增量迁移可以保留。后续的降级仅移除新的索引和表。

## 开放问题

无。当前更改有意将 AIOps 执行集成保留在仓库边界，直到该工作流被添加。
