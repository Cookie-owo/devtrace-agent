## Why

产品在知识库、聊天和AIOps数据可以安全暴露之前，需要一个真实的user边界。身份验证现在防止后续功能中嵌入难以解除的匿名访问模式。

## 什么更改

- 添加 user 注册、登录、注销和当前 user API 流程。
- 仅以安全密码哈希形式存储密码；绝不要持久化或返回明文密码。
- 使用可撤销的持有者会话，以便已认证的 API 调用可以被授权，注销可以使会话失效。
- 通过现有的 SQLAlchemy/Alembic 内存边界添加身份验证数据库表和仓库。
- 添加共享身份验证契约、OpenAPI 路径和统一的身份验证错误代码。
- 添加前端登录、注册、注销、已认证的API 客户端行为以及持久化的身份验证状态。
- 限制知识库、聊天和AIOps API 的访问，使未经过身份验证的请求接收到统一的错误封装。

## 功能

### 新功能

- `user-authentication`: 用户身份、凭证存储、会话令牌生命周期、经过身份验证的后端依赖项和前端身份验证状态。

### 修改的功能

- `api-and-sse-contracts`: 添加认证响应/错误契约、认证 OpenAPI 端点、受保护资源的安全性要求以及认证错误代码覆盖。
- `memory-repositories`: 向 SQLite 内存模式添加用户和身份验证会话持久化表/仓库操作。

## 影响

- 为 FastAPI、ASGI 测试和密码哈希添加后端依赖项。
- 添加后端身份验证域名/service/repository/API 模块和 Alembic 迁移，用于 user 和会话。
- 更新共享的 TypeScript API 合同和 OpenAPI 定义。
- 将前端 Vue 应用从仅基础页面更新为小型已认证应用外壳。
- 为注册、登录、注销、当前 user、认证状态持久化和受保护访问错误添加后端、前端和合同测试。
