## Why

本地 IDE 元数据当前在 Git 中显示为未跟踪目录。忽略它可以使仓库状态专注于项目文件，并防止编辑器特定的状态被意外提交。

## 什么更改

- 在仓库级别添加 `.gitignore`。
- 忽略 IDE 项目元数据，位于 `.idea/` 下。
- 保留现有的 OpenSpec 和 Codex 初始化文件可跟踪。

## 功能

### 新功能
- `repo-hygiene`: 用于从版本控制中排除仅限本地开发的元数据的仓库卫生规则。

### 修改的功能

## 影响

- 受影响的文件：`.gitignore`。
- 无 API、依赖项、运行时或远程 Git 更改。
