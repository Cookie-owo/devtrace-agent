# 事件报告

## 目标

把告警、日志、执行步骤和处置结果整理为便于复盘的中文 Markdown 事件报告。

## 报告结构

1. 事件摘要
2. 影响范围
3. 关键时间线
4. 证据与根因判断
5. 已执行操作及结果
6. 后续行动项

## 执行规则

- 只记录工具或用户输入提供的事实。
- 根因尚未确认时使用“待验证”，不得补全结论。
- 时间、服务名、请求标识和关键日志应保持原值。
- 失败步骤也必须进入时间线。
