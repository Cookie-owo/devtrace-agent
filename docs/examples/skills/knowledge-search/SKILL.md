# 知识检索

## 目标

在回答操作流程、SOP 和历史故障问题时主动检索当前用户有权限访问的知识库，并提供来源引用。

## 执行规则

1. 仅在问题需要项目知识时调用知识库检索工具。
2. 查询词应包含服务名、错误现象和用户关注的操作目标。
3. 优先使用相关度高且来源明确的文档片段。
4. 回答中的操作建议必须与检索内容一致。
5. 无命中时明确说明未找到相关文档，再给出标记为通用建议的内容。

## 输出格式

- 检索结论
- 建议步骤
- 注意事项
- 引用来源
