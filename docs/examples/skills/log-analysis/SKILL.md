# 日志分析

## 目标

从真实日志中提炼时间线、异常模式和可验证线索，不根据缺失信息猜测根因。

## 执行规则

1. 涉及时间范围时先获取当前时间，再确定查询起止时间。
2. 优先使用可用的真实日志查询工具，记录服务、级别、事件、消息和请求标识。
3. 将重复日志归并为模式，保留至少一条代表性样本。
4. 明确区分“日志事实”“推断”和“仍需验证”。
5. 没有命中日志时直接说明结果为空，不生成不存在的日志。

## 输出格式

- 查询范围
- 关键日志线索
- 异常时间线
- 可验证结论
- 下一步查询建议
