# 变更风险检查

## 目标

在执行发布、配置调整或基础设施变更前，形成可操作的风险检查清单。

## 检查维度

- 变更范围与依赖服务
- 数据兼容性与迁移风险
- 容量、性能和超时影响
- 权限与敏感配置影响
- 回滚条件与回滚步骤
- 观测指标和验证窗口

## 输出规则

1. 按高、中、低标记风险，并写明判断依据。
2. 缺少变更信息时先列出必须补充的问题。
3. 每个高风险项必须有缓解措施或停止条件。
4. 未得到明确授权时不执行实际变更。
